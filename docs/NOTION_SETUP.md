# Notion (optional) — Import from Google Sheets CSV

Live applications are stored in **Google Sheets**. Use Notion only if you want a copy there later.

## Import steps

1. Open your hiring Google Sheet.
2. **File → Download → Comma Separated Values (.csv)**.
3. In Notion, open (or create) a table database.
4. Use **⋯ → Merge with CSV** / Import CSV.
5. Map columns to Notion properties and import.

For collecting new applications, see **[GOOGLE_SHEETS_SETUP.md](./GOOGLE_SHEETS_SETUP.md)**.
